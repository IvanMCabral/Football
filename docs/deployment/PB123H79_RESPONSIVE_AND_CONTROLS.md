# PB1.2.3H7.9 — Responsive and controls evidence

## Browser observation

The authenticated public app was inspected at 1920×911 (viewport width 1920,
document client width 1905, document scroll width 1905, no horizontal
overflow). Login, dashboard, squad, lineup, live match and tactical modal were
reachable and usable at that viewport.

The tactical editor exposed the complete XI, bench, formation selector and
pixel-aware pre-match editor. The live formation modal paused the round and
returned to play after cancellation/confirmation. The injury dialog exposed the
injured player and substitution context.

## Not certified in this run

The required matrix of 1536, 1366, 1280, 1024, 768, 430, 390 and 360 pixel
viewports was not completed. No claim is made for those sizes, nor for the full
button inventory. This remains a release gate for the definitive public
certification.
